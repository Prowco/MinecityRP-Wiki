Official Minecity GTA Ecosystem

Minecity is a next-generation Minecraft Roleplay server built on Purpur 1.21.11 / Java 21 requiring ZERO client-side mods. Players join using standard vanilla Minecraft clients while enjoying 3D animated vehicles, firearms, proximity voice/text chat, cellphones, interactive apartments, and synchronized public safety departments.
